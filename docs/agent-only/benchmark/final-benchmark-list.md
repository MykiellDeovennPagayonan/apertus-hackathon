# Final benchmark selection

**Final benchmark: 40 experiments, with one prompt per experiment.** The first 24 appear in both peer reports; the remaining 16 are the requested additions.

“Spectrometry” is mapped to the reported Beer-Lambert spectrophotometry experiment (`beer-lambert`). Pendulum and slope are added topics absent from both reports; their catalog recipes use the IDs `pendulum` and `slope`.

Prompts mix brief requests with more specific interactions. The five original user examples are preserved verbatim; five other prompts reuse the approved examples. Submit only the prompt text, without the experiment label or catalog link. These are evaluation inputs, not recorded outcomes.

## Common to both reports

1. [projectile — Projectile motion](https://apertus-hackathon.vercel.app/experiments?experiment=projectile)

   **Prompt:** “Show me 2 projectiles distance comparison based on angles”
